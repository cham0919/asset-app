# 우리집 자산 — 아이폰 설치 가이드

구글 스프레드시트의 **웹에 게시** 주소를 읽어서 보여주는 **조회 전용** 아이폰 웹앱(PWA)입니다.
로그인이 필요 없고, 앱 스토어나 맥 없이 사파리에서 홈 화면에 추가해 앱처럼 씁니다. 처음 한 번만 아래 3단계를 하면 됩니다 (약 10분).

> ⚠️ 게시 주소를 아는 사람은 누구나 이 가계부·자산 데이터를 볼 수 있습니다. 주소는 **앱 설정 화면에만** 입력하고, GitHub 코드나 메신저에는 올리지 마세요.

---

## 1단계. 엑셀을 구글 스프레드시트로 바꾸고 웹에 게시하기

1. `자산관리.xlsx`를 구글 드라이브에 업로드합니다.
2. 드라이브에서 파일을 열고 **파일 → Google 스프레드시트로 저장**. 같은 이름의 스프레드시트 사본이 새로 생깁니다.
   - 이제부터는 **이 스프레드시트에서만 수정하세요.** 원본 .xlsx를 고치면 앱에 반영되지 않습니다. 헷갈리지 않게 원본 .xlsx는 지우거나 다른 폴더로 옮겨 두세요.
3. 스프레드시트에서 **파일 → 공유 → 웹에 게시**:
   - 범위: **전체 문서**
   - 형식: **Microsoft Excel (.xlsx)** (다른 형식을 골라도 앱이 알아서 xlsx로 바꿔 읽습니다)
   - **게시** 클릭 → 나오는 주소(`https://docs.google.com/spreadsheets/d/e/2PACX-…/pub?output=xlsx`)를 복사해 둡니다.
   - 같은 창의 **"변경사항이 생기면 자동으로 다시 게시"**가 켜져 있는지 확인하세요 (기본값 켜짐).
4. 1~3월의 예시 값은 실제 금액으로 바꾸거나 지워 주세요.
5. **지키실 것:** 시트 이름(`1월`~`12월`, `자산관리`, `설정`)과 표 머리글(`구분(1차)`, `대분류`)은 바꾸지 마세요. 항목 추가·삭제, 행 삽입·삭제는 자유롭게 하셔도 됩니다.

수정은 PC 브라우저나 아이폰의 **구글 스프레드시트 앱**에서 하면 됩니다. 수정 후 게시본에 반영되기까지 **보통 몇 분** 걸립니다.

## 2단계. 앱 파일을 인터넷에 올리기 (GitHub Pages, 무료)

1. github.com 가입 후 오른쪽 위 **+ → New repository**. 이름 예: `asset-app`, **Public** 선택 → Create.
   - 이 저장소에는 앱 코드와 예시 엑셀만 들어갑니다. 게시 주소와 실제 데이터는 올라가지 않아요.
2. **Add file → Upload files**로 이 폴더의 파일 전부(`index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-512.png`, `demo.xlsx`, `demo2025.xlsx`)를 올리고 Commit.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 주소가 생깁니다: `https://아이디.github.io/asset-app/`

## 3단계. 아이폰에 설치

1. 아이폰 **사파리**로 2단계 주소를 엽니다.
2. 아래 **공유 버튼 → 홈 화면에 추가**. 이제부터는 홈 화면 아이콘으로 엽니다.
3. 앱 오른쪽 위 ⚙️ → **웹에 게시 URL**에 1단계 주소 붙여넣기 → **게시 URL에서 불러오기**.
4. 끝! 가계부 · 월별추이 · 자산 탭이 채워집니다.

---

## 쓰면서 알아두면 좋은 것

- 앱을 열 때마다(마지막 갱신 후 1분이 지났으면) 자동으로 최신 데이터를 가져옵니다. **↻** 버튼으로 바로 갱신할 수도 있어요.
- 마지막으로 불러온 데이터는 아이폰에 저장돼서 **오프라인에서도** 볼 수 있습니다. 불러오기에 실패해도 기존 데이터는 그대로 남습니다.
- 화면 위 **연도 · 월 목록 상자**를 누르면 원하는 달로 바로 이동합니다. 값이 없는 달은 '미입력'으로 표시돼요.
- 좌우 화살표나 화면을 **밀어서** 한 달씩 이동할 수도 있어요. 12월에서 다음으로 가면 다음 해 1월로 넘어갑니다 (월별추이 탭에서는 연도 단위로 이동).
- 색상은 국내 금융 앱 관례대로 **증가 = 빨강, 감소 = 파랑**입니다.
- 주소가 유출된 것 같으면: 스프레드시트에서 **웹에 게시 → 게시 중지** 후 다시 게시하고, 앱에 새 주소를 넣으세요.

## 연도 추가하기 (2025년 기록 넣기, 새해 준비)

앱은 **연도마다 스프레드시트 1개**를 씁니다. 연도는 파일의 '설정' 시트 **기준 연도** 칸으로 자동 구분돼요.

1. 기존 스프레드시트에서 **파일 → 사본 만들기**. 이름 예: `자산관리 2025`.
2. 사본의 **설정 시트 → 기준 연도**를 `2025`로 바꾸고, 월별 금액과 자산 값을 그 해 값으로 채웁니다. 비울 칸은 지우세요.
3. 사본에서 **파일 → 공유 → 웹에 게시 → 게시** 후 주소를 복사합니다. 사본은 게시 주소가 새로 생깁니다.
4. 앱 ⚙️ → **웹에 게시 URL 추가**에 붙여넣고 **추가하고 불러오기**.
5. 화면 위쪽 **연도 목록 상자**에서 2025년을 고르면 됩니다.

- 두 연도가 이어져 있으면 **1월의 "전월 대비"는 전년도 12월과 비교**합니다. 자산 항목은 대분류·중분류·소분류 이름이 같아야 서로 맞춰집니다.
- 같은 기준 연도 파일을 두 개 등록하면 목록의 마지막 주소 것을 씁니다. ⚙️ 목록에서 연도 표시를 확인하세요.
- 연결을 **삭제**하면 그 연도 데이터도 앱에서 지워집니다. 스프레드시트 자체는 그대로예요.
- 예전 연도 파일은 더 고칠 일이 없다면 그대로 두면 됩니다. ↻를 누를 때마다 모든 연도를 함께 다시 읽어요.

## 앱을 업데이트할 때 (새 버전 반영)

1. GitHub 저장소 화면에서 **Add file → Upload files**.
2. 새로 받은 파일 중 바뀐 것(이번 버전: `index.html`, `sw.js`, `demo.xlsx`)을 끌어다 놓으면 같은 이름 파일이 덮어써집니다 → **Commit changes**.
3. 1~2분 기다린 뒤 아이폰에서 앱을 **완전히 종료**(앱 전환 화면에서 위로 밀기)하고 다시 엽니다.
   - 그래도 예전 화면이면 한 번 더 종료 후 실행하세요. 첫 실행 때 새 버전을 내려받고, 다음 실행부터 적용됩니다.
4. 게시 URL과 불러온 데이터는 그대로 유지됩니다. 다시 입력할 필요 없어요.

## 엑셀(스프레드시트) 양식이 바뀌었을 때

- **아직 실제 데이터를 입력하지 않았다면:** 기존 스프레드시트에서 **파일 → 가져오기 → 업로드**로 새 `자산관리.xlsx`를 고르고 **스프레드시트 교체**를 선택하세요. 같은 파일이 갱신되므로 게시 주소가 그대로입니다. 이후 **파일 → 공유 → 웹에 게시**에서 "게시 중" 상태인지 한 번 확인하세요.
- **이미 데이터를 입력했다면:** 새 파일로 교체하지 말고, 바뀐 부분만 기존 스프레드시트에 직접 추가하는 편이 안전합니다.

## 홈 탭

| 카드 | 계산 대상 | 아래 표시 |
|---|---|---|
| 총자산 / 순자산 | 자산관리 시트 합계 | 연평균 수익률 |
| 부채 | 대분류 '부채' 합계 | 총자산 대비 비율 |
| 금융투자 | 참주식 · 정윤주식 · 참퇴직금 · 정윤퇴직금 · 비트코인 | 연평균 수익률 |
| 부동산 | 중분류 '부동산' (아파트) | 연평균 수익률 |
| 현금비중 | (현금 · 복지포인트 · 예비현금 · 참청약 · 정윤청약) ÷ 순자산 | 현재 현금 |

- '현재'는 오늘 이전에서 자산을 입력한 가장 최근 달입니다 (등록된 모든 연도 통틀어).
- 연평균 수익률 = 처음 기록한 달 → 현재까지의 잔액 변화를 1년 단위로 환산한 값(CAGR)입니다. 저축·추가 납입이 포함되고, 기록 기간이 1년 미만이면 크게 보일 수 있어요.
- 엑셀에 새 자산 항목을 추가했는데 위 분류에 속하지 않으면 홈에 **'분류되지 않은 자산'** 안내가 뜹니다. 이름을 위 목록에 맞추거나, 분류 추가를 요청하세요.

## 분석 탭

- **예측:** 다음 달 순자산 = 이번 달 순자산 × (1 + 월 수익률) + 월 저축
  - 수익률 = 실제 기록의 '저축 제외' 순자산 증가율(연환산, 부동산 시세 변동 포함)
  - 월 저축 = 가계부 최근 12개월 평균 저축 합계(일반 + 대출상환)
- **계획(회색 선):** 매년 말 순자산 = 전년도 말 × (1 + 계획 수익률) + 계획 연 저축. 기본값 25% · 3,000만원 · 2025년 시작. 시작값(2024년 말 순자산)을 비워 두면 첫 기록값을 씁니다.
- **계획 대비:** 계획 곡선이 지금 순자산에 도달하는 시점과 오늘의 차이(앞섬/뒤처짐). 연말 사이 월별 값은 직선으로 이어 계산해요.
- **목표 진척도 · 마일스톤:** 5억 · 10억 · 20억 · 목표의 달성(예정) 시점과 계획 시점.
- **시뮬레이터:** 월 저축액 · 수익률을 바꿔 달성 시점을 미리 봅니다 (저장되지 않음).
- **FIRE:** 원금 × 8% × 75% = 연 실수령 배당, ÷12 = 월. 원금은 '금융자산'(금융투자 + 현금) 또는 '순자산 전체' 중 선택.
- 목표 금액과 계획 조건은 ⚙️ → **분석 · 목표와 계획**에서 바꿀 수 있어요.

## 월말 레포트 (가계부 > 오른쪽 위 '월말 레포트' 버튼)

가계부 화면에서 버튼을 누르면 선택한 달의 결산을 볼 수 있어요. 그 달에 레포트가 있으면 버튼에 빨간 점이 표시돼요.

- **자동 결산 (항상 표시):** 수입·지출·일반/대출상환 저축·저축률의 전월 대비, 전년 동월 대비, 투자 성과(금융투자·부동산 항목별 전월 대비), 평소와 달랐던 지출(직전 6개월 평균 대비 10만원·20% 이상 차이), 순자산 변동(저축 + 저축 외 변동), 목표 진척도
- **월간 레포트:** 스프레드시트의 **'결산' 시트**에 기록된 글을 문서처럼 보여줘요.
  - 1행 머리글: `연월 | 작성일 | 제목 | 한 줄 요약 | 본문 | 상태`
  - 한 달에 한 줄. 연월은 `2026-10` 형식, 상태는 `초안` 또는 `확정`
  - 본문은 마크다운 일부를 지원해요: `##`/`###` 제목, `-` 목록(두 칸 들여쓰기로 하위 목록), `**굵게**`, `|`표
  - 레포트는 Claude가 Google Sheets 연동으로 직접 기록하거나, 직접 붙여넣어도 돼요.
- **지난 결산:** 모든 연도의 레포트 목록. 누르면 그 달로 이동해요.
- 엑셀 양식에 빈 '결산' 시트가 들어 있어요. 기존 스프레드시트에는 같은 머리글로 시트를 하나 추가하면 돼요.

## 앱이 계산하는 값

엑셀 수식 결과를 읽지 않고, 입력한 원본 숫자로 앱이 직접 계산합니다 (엑셀과 같은 공식).

| 항목 | 계산 |
|---|---|
| 일반 저축 | 수입 − 지출 (가계부) |
| 대출상환 저축 | 전월 부채 합계 − 이번 달 부채 합계 (줄어든 만큼만, 늘어난 달은 0). 1월은 설정 시트 '전년 12월 말 부채' 값, 비어 있으면 등록된 전년도 파일의 12월 값 |
| 총자산 / 순자산 | 유동 + 비유동 / 총자산 − 부채 |
| 순자산 수익률 | (이번 달 순자산 − 전월 순자산) ÷ 전월 순자산 |
| 저축 합계 | 일반 저축 + 대출상환 저축 |
| 저축 외 자산 변동 | 순자산 증감 − 저축 합계 = 투자손익, 시세 변동 등 |
| 저축 제외 수익률 | 저축 외 자산 변동 ÷ 전월 순자산 |

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "게시 URL 형식이 아니에요" | 공유 링크(`/d/…/edit`)가 아니라 **웹에 게시**에서 받은 `/d/e/2PACX-…` 주소인지 확인 |
| "게시가 중지됐거나 주소가 바뀌었어요" | 스프레드시트에서 웹에 게시 상태 확인, 다시 게시했다면 새 주소 입력 |
| 수정했는데 앱에 안 바뀜 | 몇 분 기다린 뒤 ↻. 원본 .xlsx가 아니라 스프레드시트를 고쳤는지 확인 |
| "네트워크 연결 또는 접근이 차단됐어요" | 인터넷 연결 확인. 계속되면 구글이 게시 주소의 외부 접근 방식을 바꾼 경우라 앱 수정이 필요합니다 |
| 앱 업데이트 후 화면이 그대로 | 앱을 완전히 닫았다가 다시 열기 |
